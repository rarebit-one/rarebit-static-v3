## New Features in Heyarr-Core

The heyarr-core repository introduced several new features this week. The Subsonic compatibility gateway for device-side personal state was added ([PR 388](https://github.com/rarebit-one/heyarr-core/pull/388)), as well as a Newznab usenet indexer provider ([PR 383](https://github.com/rarebit-one/heyarr-core/pull/383)). Additionally, an OPDS library and download adapter for publications was implemented ([PR 377](https://github.com/rarebit-one/heyarr-core/pull/377)).

## Dependency Updates in Harness-Kernel

Two dependency update pull requests were merged in the harness-kernel repository. The actions-all group received two updates ([PR 47](https://github.com/rarebit-one/harness-kernel/pull/47)), and the minor-patch group was updated with five updates ([PR 46](https://github.com/rarebit-one/harness-kernel/pull/46)). This follows the release of harness-kernel v0.6.0, introducing the self-hosted local provider ([Release v0.6.0](https://github.com/rarebit-one/harness-kernel/releases/tag/v0.6.0)).
