## Public Repository Enhancements

In the [.github repository](https://github.com/rarebit-one/.github/pull/79), auto-merge capabilities have been enabled using a Personal Access Token (PAT) to ensure that merges trigger push events properly. This adjustment is further complemented by the ability to let the maintainer's own pull requests auto-land ([.github PR 78](https://github.com/rarebit-one/.github/pull/78)).

The auto-lander path has been opted into across multiple repositories, including [rarebit-static-v3](https://github.com/rarebit-one/rarebit-static-v3/pull/322), [standard_circuit](https://github.com/rarebit-one/standard_circuit/pull/67), and others.

## Configuration Changes

Updates to the .gitignore files have been made in the [.github](https://github.com/rarebit-one/.github/pull/80) and [rarebit-static-v3](https://github.com/rarebit-one/rarebit-static-v3/pull/323) repositories to ignore worktree directories.
