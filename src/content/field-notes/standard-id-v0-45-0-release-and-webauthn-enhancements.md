## standard_id v0.45.0 Release

The release of [standard_id v0.45.0](https://github.com/rarebit-one/standard_id/releases/tag/v0.45.0) is now available with several new features and fixes. Key updates include gating refresh grants and rolling back refused links as per [PR 363](https://github.com/rarebit-one/standard_id/pull/363). Also notable is the [SOCIAL_LINK_BLOCKED fix](https://github.com/rarebit-one/standard_id/pull/365) for handling conflicts in provider-sub authentications.

## WebAuthn Updates in void-which-binds-web

[void-which-binds-web](https://github.com/rarebit-one/void-which-binds-web/pull/7) introduced enhancements to the WebAuthn invite and enrolment ceremony, including new enrolment proof capabilities.

## Dependency Updates

The [harness-kernel](https://github.com/rarebit-one/harness-kernel/pull/67) project continued its routine dependency maintenance efforts with updates focusing on minor and patch version upgrades. Across private systems, 1130 runs completed with an 87% success rate, reflecting stable operations.
